# 将棋アプリ

ブラウザ上で友達と対戦できる将棋アプリです。

ルームを作成してルームIDを共有することで、友達と通信対戦できます。

基本的な将棋のルール・対局機能に加えて、対局をサポートする機能として「駒の利き表示」と「仮移動」を実装しています。

URL：https://frontend.asahi-dev.workers.dev/

## 機能

### 通信対戦

* ルームを作成して友達と対戦
* ルームIDを共有して対局相手を招待
* リアルタイムで盤面・手番を同期

### 将棋機能

* 駒の移動・成り・駒打ち
* 王手・詰みの判定
* 待った
* 投了
* 棋譜再生
* 先手・後手の選択
* その他、基本的な将棋のルールに対応

### 対局サポート

#### 駒の利き表示

盤上の駒がどのマスに利いているかを表示できます。

角や飛車などの長い利きを持つ駒の利きを確認したり、不意の王手や利きの見落としを防ぐためのサポート機能です。

#### 仮移動

駒を実際には動かさずに、移動後の盤面を確認できます。

駒を動かした場合に盤面がどう変化するかを確認しながら、次の手を考えることができます。

### その他

* 将棋盤の背景変更
* 効果音のミュート
* 音声案内
* クレジット表示

## 使用技術

* TypeScript
* Next.js
* React
* Hono
* Cloudflare Workers
* Cloudflare Durable Objects
* WebSocket

## システム構成

通信対戦にはCloudflare Durable ObjectsとWebSocketを使用しています。

ルームごとにDurable Objectを割り当て、参加しているプレイヤー間で指し手や手番などをリアルタイムに同期しています。
